## これは何

意志で我慢する制限アプリは自分で解除できてしまい、効かなかった。問題は「使えてしまうこと」ではなく「無意識に指が動くこと」だと考え、行動を禁止するのではなく、開いた瞬間に理由を選ばせて一拍おかせる設計にした。

- SNSを開くと理由を4つ（暇つぶし／逃避／調べもの／勉強や仕事）から選ばせる
- 理由ごとに違う言葉で返す。無意識寄りの理由なら「やめておく」を、目的がある理由なら「それでも開く」を主ボタンにする
- 開いた回数・引き返した回数を軸に、「取り戻した時間」（引き返した回数×理由ごとの分数）と「時間帯×理由のヒートマップ」を見せる。どちらもスクリーンタイムには出せない指標
- 理由の色は無意識＝赤系／目的あり＝青系の2系統に統一し、ラベルでも補強

## 技術的な壁

iOSではWebアプリから他アプリの上に画面を重ねられないため、OSのショートカット（オートメーション）を引き金にWebアプリを挟む構成にしている。実装後、SNSへ戻るたびにオートメーションが再発火して無限ループになる問題に直面した。クリップボードに使い捨ての「通行証」を書き込み、戻ってきた回だけ素通りさせることで解決した（[SHORTCUTS-SETUP.md](SHORTCUTS-SETUP.md)）。
